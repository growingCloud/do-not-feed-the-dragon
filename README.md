# 🐲 Do not feed the dragon

드래곤을 배터지게 하지 않으면서 먼저 손패를 비우는 턴제 심리전 카드게임. 나 혼자 vs AI 3명(총 4인)으로 즐기는 순수 프론트엔드 웹게임입니다.

## 게임 규칙

- 시작 시 각자 **7장**의 카드를 받습니다.
- 카드는 **먹이 카드(1~5)**, **스킬 카드**로 구성됩니다.
- 드래곤의 최대 포만감은 **포만감 카드(10~20, 11장)** 로 매번 정해집니다.
- 내 턴에는 **먹이 카드 1장**(두번먹이기로 늘릴 수 있음)과 **스킬 카드 2장**을 낼 수 있어요.
- 먹이 숫자가 드래곤에 누적됩니다.
  - **딱 맞게 채우면** → 만족! 포만감 리셋 + **핸드의 카드 1장을 골라 버릴 수 있어요(보상)**
  - **넘기면** → 낸 사람이 패널티로 **3장** 즉시 드로우 + 리셋
- 내 턴이 **시작할 때마다 2장 드로우**. 먹이를 한 장도 못 내면 추가 패널티 **1장**.
- 실수한 카드는 **실행 취소**로 되돌릴 수 있어요(턴당 1회). 단, 드래곤이 반응(리셋/초과)한 뒤로는 잠깁니다.
- **승리 조건**: 손패를 먼저 비우면 즉시 승리. 그전에 **5라운드**가 끝나면 손패가 가장 적은 사람이 승리 (동점이면 남은 **먹이 숫자 합**이 작은 사람).
- **난이도**: 시작 화면에서 쉬움 / 보통 / 어려움 선택 (AI의 판단 수준이 달라짐).

### 밸런스 조정

게임 밸런스 수치는 [`src/game/engine.js`](src/game/engine.js)의 `RULES` 객체 한 곳에서 조정합니다 (시작 손패, 턴당 드로우, 스킬 제한, 라운드 수, 패널티 등).

### 스킬 카드

| 카드 | 효과 |
| --- | --- |
| 두번먹이기 🍽️ | 이번 턴에 먹이를 2장까지 낼 수 있음 |
| ×2 ✖️ | 이번 턴에 내는 다음 먹이 숫자를 2배로 |
| -2 🔽 | 드래곤 현재 포만감 -2 |
| 뒤집기 🔄 | 턴 진행 방향 반전 |
| 소화 💨 | 드래곤 현재 포만감 -5 (최강) |

## 기술 스택

- [Vite](https://vite.dev/) + [React](https://react.dev/) (순수 프론트엔드)
- 상태 관리는 순수 함수형 게임 엔진 (`src/game/`)

## 로컬에서 실행

```bash
npm install
npm run dev
```

## 프로덕션 빌드

```bash
npm run build      # dist/ 생성
npm run preview    # 빌드 결과 미리보기
```

## 프로젝트 구조

```
src/
  game/
    cards.js     # 카드/덱 정의, 셔플
    engine.js    # 게임 상태 & 규칙 (순수 함수, 상태 변형)
    ai.js        # AI 상대 휴리스틱
  components/    # UI 컴포넌트 (타이틀, 드래곤, 카드, 로그, 결과 등)
  App.jsx        # 게임 오케스트레이션
  main.jsx       # 진입점
  styles.css
```
